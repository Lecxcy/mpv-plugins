# 要交给 mpv-multi.app 处理的视频 UTI 清单。
#
# 这份清单同时驱动两件事：
#   1. make-mpv-multi-app.sh 用它生成 app 的 CFBundleDocumentTypes；
#   2. set-video-handlers.sh 用它生成 duti 绑定。
# 两边共用一份，是为了避免"app 没声明但 duti 绑了"这种半吊子状态——那种
# 绑定在 Finder 的"打开方式"里不出现，且系统重建 LaunchServices 数据库后
# 容易被别的 app 顶掉。
#
# 为什么不是直接抄 mpv.app 的列表：mpv 只声明了自己那套（含它自造的
# io.mpv.*），漏掉了同扩展名的系统原生 UTI，缺口就被 QuickTime / Chrome
# 占了位。下面标了「补」的就是这些漏网的。一个扩展名只要有任何一个 UTI
# 没绑，那个扩展名就会时灵时不灵。
#
# 空行和 # 开头的行会被忽略。改完这里要重跑：
#   scripts/make-mpv-multi-app.sh && scripts/set-video-handlers.sh
